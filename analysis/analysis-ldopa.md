
# L-DOPA spatial transcriptomics analysis

## 1. Preprocessing

### 1.1. Space Ranger

Spatial transcriptomics reads were initially aligned and counted using **Space Ranger v1.3.1** with the standard 10x Genomics mouse reference (`refdata-gex-mm10-2020-A`).

```bash
export PATH=/home/mateusz/projects/ifpan-janrod-spatial/tools/spaceranger-1.3.1:$PATH
```

**Script:** [`spaceranger-analysis.sh`](../preprocessing/spaceranger-analysis.sh)

The script runs `spaceranger count` for samples defined in the metadata file.

```bash
bash preprocessing/spaceranger-analysis.sh \
  --transcriptome raw/refdata-gex-mm10-2020-A/ \
  --output-dir data/spaceranger/ \
  --samples $(cat data/samples-spatial-metadata.tsv | sed 1d | cut -f1 | tr "\n" "," | sed 's/,$//') \
  --metadata data/samples-spatial-metadata.tsv \
  --localcores 20
```

The metadata file provides sample-specific information required by Space Ranger, including sample identifiers, Visium slide/capture-area information and corresponding spatial alignment files.

### 1.2. Identification and annotation of transcript regions

BAM files generated by Space Ranger were merged to obtain sequencing information across samples used in the L-DOPA experiment.

```bash
samtools merge \
  -@ 20 \
  data/ldopa/merged-samples.bam \
  <sample BAM files>
```

```bash
samtools index \
  data/ldopa/merged-samples.bam
```

Genomic regions represented in the sequencing data were identified using MACS3.

```bash
macs3 callpeak \
  -t data/ldopa/merged-samples.bam \
  --outdir data/ldopa/macs3/
```

The detected regions were annotated relative to gene and LTR annotations.

**Script:** [`prepare-annotate-peaks.sh`](../preprocessing/prepare-annotate-peaks.sh)

```bash
bash preprocessing/prepare-annotate-peaks.sh \
  --gene-bed data/mart-export-v102-mm10.bed \
  --ltr-bed data/ltr-grcm38-mm10.bed \
  --macs-peaks <MACS3 peaks file> \
  --data-dir data/ldopa/ \
  --number-threads 20
```

The script assigns gene/LTR information, determines strand based on sequencing coverage and associates detected regions with nearby genes.

### 1.3. Transcript filtering and customized reference

Detected transcript regions were filtered using the striatal Nanopore cDNA reference and further reduced to remove low-coverage regions.

```bash
bedtools intersect \
  -a data/ldopa/peaks-annotate-sort.bed \
  -b data/str-cdna-nanopore.bed \
  -wa -wb | \
  awk '{print $0, ($16==$22?_:"NOT") "MATCH"}' | \
  grep -v NOT | \
  cut -f 1-17 | \
  sort | \
  uniq \
  > data/ldopa/peaks-annotate-filt-nanopore.bed
```

**Script:** [`reduction-peaks.R`](../preprocessing/reduction-peaks.R)

```bash
Rscript preprocessing/reduction-peaks.R \
  --file_info_peaks data/ldopa/peaks-annotate-filt-nanopore.bed \
  --bam_file data/ldopa/merged-samples.bam \
  --output_tsv data/ldopa/peaks-annotate-reduction.tsv \
  --number_cores 20 \
  --peak_counts 1200 \
  --amplitude_peak 400 \
  --ratio_counts_amplitude 1.4
```

The filtered transcript annotation was converted to GTF format.

**Script:** [`bed2gtf-spaceranger.py`](../preprocessing/bed2gtf-spaceranger.py)

```bash
python3 preprocessing/bed2gtf-spaceranger.py \
  --input data/ldopa/peaks-annotate-reduction.tsv \
  --output data/ldopa/peaks-annotate-reduction.gtf
```

A customized Space Ranger reference was then prepared:

```bash
spaceranger mkref \
  --genome=corrected-reference \
  --fasta=raw/refdata-gex-mm10-2020-A/fasta/genome.fa \
  --genes=data/ldopa/peaks-annotate-reduction.gtf
```

The spatial transcriptomics samples were subsequently processed using the customized reference to obtain gene expression count matrices for downstream analysis.
