
# Risperidone spatial transcriptomics analysis

## 1. Data preprocessing

### 1.1. Initial read alignment and gene counting

Spatial transcriptomics reads were initially aligned and counted using **Space Ranger v1.3.1** and the standard 10x Genomics mouse transcriptome reference (`refdata-gex-mm10-2020-A`).

**Script:** [`spaceranger-analysis.sh`](../preprocessing/spaceranger-analysis.sh)

```bash
export PATH=/home/mateusz/projects/ifpan-janrod-spatial/tools/spaceranger-1.3.1:$PATH
```

```bash
bash preprocessing/spaceranger-analysis.sh \
  --transcriptome raw/refdata-gex-mm10-2020-A/ \
  --output-dir data/spaceranger/ \
  --metadata data/metadata-antipsychotics.tsv \
  --samples $(cat data/metadata-antipsychotics.tsv | grep -P "risperidone|saline" | sed 1d | cut -f1 | tr "\n" "," | sed 's/,$//') \
  --localcores 40
```

The script runs `spaceranger count` for the selected samples. Sample metadata are used to provide the sample ID, Visium slide ID, capture area, tissue image and corresponding spatial alignment JSON file required for each Space Ranger run.

### 1.2. Identification and annotation of transcript regions

BAM files generated by Space Ranger for all risperidone and saline samples were merged into a single alignment file. Combining the samples provided a common collection of aligned sequencing reads used to identify transcribed genomic regions across the complete experiment.

```bash
samtools merge \
  -@ 42 \
  data/risperidone/gene-annotation/merged-samples.bam \
  `cat data/metadata-antipsychotics.tsv | \
    grep -P "saline|risperidone" | \
    cut -f1 | \
    xargs -i bash -c 'find data/spaceranger/{}/SPATIAL_RNA_COUNTER_CS/ -name *.bam'`
```

```bash
samtools index \
  data/risperidone/gene-annotation/merged-samples.bam
```

MACS3 was used to identify genomic regions with concentrated sequencing signal.

```bash
docker run \
  --rm \
  -u 10007:10000 \
  --name macs3 \
  -v $PWD:/ifpan-janrod-spatial/ \
  matzieb/macs3 \
  macs3 callpeak \
  -t /ifpan-janrod-spatial/data/risperidone/gene-annotation/merged-samples.bam \
  --outdir /ifpan-janrod-spatial/data/risperidone/gene-annotation/macs3
```

The identified regions were subsequently annotated relative to protein-coding genes and LTR elements, and strand information was assigned based on sequencing coverage.

**Script:** [`prepare-annotate-peaks.sh`](../preprocessing/prepare-annotate-peaks.sh)

```bash
bash preprocessing/prepare-annotate-peaks.sh \
  --gene-bed data/mart-export-v102-mm10.bed \
  --ltr-bed data/ltr-grcm38-mm10.bed \
  --macs-peaks data/risperidone/gene-annotation/macs3/risperidone_peaks.narrowPeak \
  --data-dir data/risperidone/gene-annotation/ \
  --number-threads 40
```

The script:

- identifies regions overlapping LTR elements;
- prepares strand-specific BAM files;
- calculates sequencing coverage separately for the positive and negative strands;
- assigns strand information based on coverage;
- assigns nearby genes using `mart-export-v102-mm10.bed` within a ±30 kb interval;
- combines the resulting gene/LTR, strand and genomic annotations.

### 1.3. Nanopore filtering and transcript annotation reduction

Nanopore cDNA sequencing data from the striatum were used as an independent transcript-level reference to retain only regions with evidence of transcription in this brain region.

```bash
bedtools intersect \
  -a data/risperidone/gene-annotation/peaks-annotate-sort.bed \
  -b data/str-cdna-nanopore.bed \
  -wa -wb | \
  awk '{print $0, ($16==$22?_:"NOT") "MATCH"}' | \
  grep -v NOT | \
  cut -f 1-17 | \
  sort | \
  uniq \
  > data/risperidone/gene-annotation/peaks-annotate-filt-nanopore.bed
```

The remaining regions were further reduced to remove low-coverage and weakly supported transcript regions. Filtering used a minimum peak count of **1200**, minimum peak amplitude of **400**, and count-to-amplitude ratio threshold of **1.4**.

**Script:** [`reduction-peaks.R`](../preprocessing/reduction-peaks.R)

```bash
docker run \
  -v `pwd`:`pwd` \
  -u 10007:10000 \
  --rm \
  matzieb/rstudio-4.1.2-bioconductor-peaks \
  Rscript `pwd`/preprocessing/reduction-peaks.R \
  --file_info_peaks `pwd`/data/risperidone/gene-annotation/peaks-annotate-filt-nanopore.bed \
  --bam_file `pwd`/data/risperidone/gene-annotation/merged-samples.bam \
  --output_tsv `pwd`/data/risperidone/gene-annotation/peaks-annotate-reduction.tsv \
  --number_cores 40 \
  --peak_counts 1200 \
  --amplitude_peak 400 \
  --ratio_counts_amplitude 1.4
```

### 1.4. Preparation of the customized reference, read alignment and gene counting

The filtered transcript regions were used to prepare a customized transcriptome reference. The reduced annotation was converted to GTF format and combined with the mouse genome sequence to create the customized Space Ranger reference.

**Script:** [`bed2gtf-spaceranger.py`](../preprocessing/bed2gtf-spaceranger.py)

```bash
python3 preprocessing/bed2gtf-spaceranger.py \
  --input data/risperidone/gene-annotation/peaks-annotate-reduction.tsv \
  --output data/risperidone/gene-annotation/peaks-annotate-reduction.gtf
```

```bash
spaceranger mkref \
  --genome=corrected-reference \
  --fasta=raw/refdata-gex-mm10-2020-A/fasta/genome.fa \
  --genes=data/risperidone/gene-annotation/peaks-annotate-reduction.gtf && \
  mv corrected-reference data/risperidone
```

All risperidone and saline samples were then processed again with Space Ranger using the customized reference.

```bash
bash preprocessing/spaceranger-analysis.sh \
  --transcriptome data/risperidone/corrected-reference \
  --output-dir data/spaceranger/ \
  --metadata data/metadata-antipsychotics.tsv \
  --samples $(cat data/metadata-antipsychotics.tsv | grep -P "risperidone|saline" | sed 1d | cut -f1 | tr "\n" "," | sed 's/,$//') \
  --localcores 40
```

The resulting spatial gene expression count matrices were used for downstream analysis.
